실시간 센서 융합 연구개발 성과 요약

골프존 소프트웨어 연구개발 지원 · CARLA RadarVision

센서 취득부터 정량 검증까지 연결한 응용 소프트웨어

영상 검출이 끊긴 기존 차량 트랙을 레이더로 보조하고, 품질 조건에 따라 최종 거리를 선택하는 시스템을 구성했다. C++/CUDA 검출 모듈 연동, Python 기반 취득·추적·기록, Qt 실시간 검증, 저장 세션 재생 평가를 하나의 흐름으로 연결했다.

핵심 결과

동일 레이더 보정 예측 437건에서 거리 MAE 1.328→0.805m, 39.4% 감소. RMSE는 1.684→1.261m로 25.1% 감소했다. 영상 추적+거리 선택 대비 보조 추적의 추가 MAE 감소율은 25.6%다. [S01-S03]

구현한 문제 해결

프레임 정렬: 센서 주기 설정과 별개로 같은 CARLA frame의 RGB·레이더·GT만 연결했다. 원본과 결과에 시각·센서·프레임을 남겨 재생 가능한 계측 자료로 관리했다.

보정과 선택 분리: 군집 점 수·거리 편차·최근 앵커·연관 모호성·이동량을 검사해 예측 박스를 제한적으로 갱신했다. 최종 레이더 거리는 최소 3점, 중앙값 편차 ≤0.5m, 카메라 거리와 ≤1m 일치 및 시간 검사 통과 시 선택했다.

검증 Tool: Qt에서 비교 영상·센서 상태·수신률·거리 출처·저장 누락을 확인하고, 시간 지정 녹화·날씨 워크플로·세션/날씨/통합 보고서 생성을 지원했다.

이 수치는 9개 조건에서 선택된 보정 표본의 결과다. 전체 미검출 구간·실환경·골프공 계측의 일반 성능을 뜻하지 않는다. 작성일 2026년 10월 24일.

평균 개선 뒤의 선택 조건까지 확인

437건은 최종 레이더 선택 242건과 카메라 대체 195건으로 나뉜다. 동일 집단 내 M1→M3 MAE 감소율은 각각 80.9%, 8.8%였다. 두 집단 평균 차이는 품질·거리·장면 차이가 있는 선택 결과이므로 레이더 사용 자체의 인과효과로 주장하지 않는다.

전체 437건에서 절대오차가 줄어든 표본은 320건, 증가한 표본은 94건, 동일한 표본은 23건이었다. 강한 비·낮에서는 평균 오차가 악화됐다. 평균 개선 외에 실패 조건과 미산출 사유까지 남겨 후속 개선 대상을 확인했다.

구현 범위를 명확히 제시

현재 실행 구조는 Python 추적·융합·GUI·평가와 외부 C++/CUDA 추론 모듈의 결합이다. Windows DLL 연동·CMake 빌드 기록, 별도 TCP 클라이언트와 Linux 서버 소스가 근거다. 독립 C++ Core와 전체 양 OS 빌드 검증은 기존 기록을 재생해 결과를 비교하는 후속 이식 과제로 설계했다.

레이더 입력은 시뮬레이터의 거리·각도·속도 검출점이다. 원시 I/Q의 FFT·필터 DSP와 MCU/FPGA 장비 연동은 별도 모듈·검증이 필요한 확장 영역이다. 골프공·클럽 계측에 적용할 때에는 센서 분해능·트리거 지연·운동 모델을 새로 정의해야 한다.

함께 제출할 상세 자료

센서 융합 연구보고서 13쪽: GT·모집단, 영상 추적과 레이더 보정 규칙, 세 방법의 공통 표본 성능, 하위집단·날씨·거리 분석, 한계와 재현 자료.

실시간 아키텍처 설계서 7쪽: 취득·추론·기록·GUI 경계, 모듈 계약, C ABI·TCP, 오류·누락 처리, 재생 평가, C++ Core 확장 설계.

근거 [S01-S15]와 원본 경로는 근거 색인에 연결했다. 데이터 취득에서 산출값의 검증과 실패 원인 확인까지 이어지는 개발 과정을 상세 자료에서 확인할 수 있다.
