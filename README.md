# CARLA RadarVision
CARLA 가상 주행 환경에서 **카메라로 차량을 검출·추적하고 레이더 측정값을 결합해 차량 간 거리를 추정**하는 프로젝트입니다. 실행 중인 차량에 카메라·레이더 등의 센서를 부착하고, 결과를 Qt 화면에 표시하거나 세션으로 저장합니다.

**동영상** : **CARLA 시뮬레이션**

https://github.com/user-attachments/assets/3348c5f7-52f8-4de5-afcb-39ad1498cd0f

**시뮬레이션 기반 검증**
CARLA 시뮬레이터를 활용하면 실제 차량과 카메라, 시험 장소를 준비하지 않고도 영상처리 파이프라인을 검증할 수 있습니다. 장비 대여·설치와 도로 시험에 드는 비용과 준비 시간을 줄이고, 같은 주행 조건을 반복 재현해 결과를 빠르게 비교할 수 있습니다.

주행 경로, 속도, 날씨, 조명, 객체 위치를 통제할 수 있어 조건별 성능 변화를 체계적으로 분석할 수 있습니다. 시뮬레이터가 제공하는 객체 정보를 기준값(Ground Truth)으로 활용하면 검출 정확도와 위치 오차를 측정하고, FPS와 처리 지연 시간도 함께 평가할 수 있습니다. 실제 도로에서 위험하거나 반복하기 어려운 상황도 안전하게 시험할 수 있습니다.
- 비용 절감: 실제 차량, 센서, 시험 장소를 준비하는 데 드는 비용 감소
- 시간 절약: 장비 설치와 도로 시험 준비 없이 빠르게 실험 시작
- 반복 재현: 동일한 주행 조건을 재생해 알고리즘 변경 전후 비교
- 정량 분석: 정확한 Ground Truth 기반 정확도·오차와 FPS·지연 시간 측정
- 안전한 시험: 위험 상황이나 재현이 어려운 조건을 시뮬레이션에서 검증
시뮬레이션 결과는 통제된 가상 환경에서의 검증 결과이며, 실제 도로 환경의 성능을 그대로 보장하지는 않습니다.

## 카메라·레이더 거리 융합과 평가

여기서 거리는 **내 차와 상대 차의 차체 사이 간격**입니다. 센서 추정에는 내 차의 위치·차체 크기를 좌표 기준으로 사용합니다. 상대 차의 CARLA 위치·차체 크기는 정답 거리(GT)를 만들고 결과를 평가할 때만 사용합니다.

1. **같은 시점의 측정값 연결:** 카메라·레이더를 약 15 FPS로 수집하고 CARLA 프레임 번호가 같은 측정값만 연결합니다. 레이더 점을 카메라 영상에 투영해 YOLO 차량 상자에 들어오는 점을 해당 차량 후보로 둡니다.
2. **카메라 기본 거리:** YOLO 상자의 아래쪽 중심에서 지면으로 광선을 투영해 상대 차의 관측 지점을 찾습니다. 그 지점부터 내 차 차체 외곽까지의 평면 거리를 구합니다. 평평한 지면과 상자 하단이 차체의 지면 접점에 가깝다는 가정을 사용합니다.
3. **레이더 후보 검사:** 영상 상자에 들어온 점 중 카메라 추정 위치와 크게 어긋나는 점을 제외합니다. 남은 점을 거리순으로 묶고, 가장 가까운 쪽에서 **3점 이상**이며 거리 중앙값으로부터 최대 편차가 **0.5m 이하**인 묶음을 찾습니다. 이전 프레임의 추적 위치에서 비현실적으로 멀리 이동한 점도 제외합니다.
4. **최종 거리 선택:** 유효한 묶음의 레이더 점들에서 내 차 차체 외곽까지의 거리 중앙값을 계산합니다. 이 값이 카메라 거리와 **1m 이내**로 일치하면 레이더 거리를 최종값으로 사용하고, 조건을 만족하지 않으면 카메라 거리를 사용합니다. 두 거리를 가중평균하지 않습니다. 화면에 표시되는 2차원 위치 좌표의 융합은 이 거리 선택과 별도 계산입니다.

저장 세션에서는 다음 세 방법을 **같은 차량·프레임 표본**에서 비교합니다.

| 방법 | 차량 ID 연결 | 최종 거리 |
| --- | --- | --- |
| 트래킹 + 카메라 | 영상 검출 상자 기반 | 카메라 추정 |
| 트래킹 + 카메라·레이더 | 영상 검출 상자 기반 | 조건을 통과한 레이더 거리, 그 외 카메라 거리 |
| 레이더 보조 트래킹 + 카메라·레이더 | 영상 상자와 레이더 거리·속도 기반 | 동일한 거리 선택 규칙 |

**YOLO+레이더 융합 기록**을 종료한 뒤 **저장 세션 3~15m 실험 결과 생성** 버튼에서 세션을 선택하면 보고서를 만듭니다. GT는 같은 프레임의 내 차와 상대 차의 **회전된 CARLA bounding box 외곽 사이 최단 평면 거리**입니다. GT 간격이 **3m 이상 15m 이하**인 차량만 평가합니다.(yolo 검출이 잘되는 구간) 결과는 세션의 `experiment_results/`에 Markdown 보고서, JSON 요약, 차량·프레임별 CSV로 저장됩니다. MAE는 절대 거리 오차의 평균이고, RMSE는 큰 오차에 더 민감한 제곱평균제곱근입니다.

2026-10-21 Town02 저장 세션 한 건에서는 GT 차량·프레임 기회 258건 중 세 방법 모두 거리 산출에 성공한 공통 표본이 254건이었습니다.

| 방법 | 공통 표본 거리 MAE | 공통 표본 거리 RMSE | 레이더 거리 선택 |
| --- | ---: | ---: | ---: |
| 영상기반 트래킹 + 카메라 | 0.952m | 1.210m | 0/254건 |
| 영산기반 트래킹 + 카메라·레이더 | 0.917m | 1.199m | 47/254건 |
| 레이더 보조 트래킹 + 카메라·레이더 | 0.917m | 1.199m | 47/254건 |

**레이더 보조 트래킹과 영상기반 트래킹의 트래킹 성능이 크게 다르지 않아서 차이가 없음**

레이더 거리를 선택한 47건에서 카메라 거리 MAE는 1.079m, 선택한 레이더 거리 MAE는 0.891m였습니다. 나머지 207건은 카메라 거리를 사용했습니다. 두 트래킹 방식의 거리 오차가 이 세션에서 같아 레이더 보조 추적의 ID 유지 효과는 이 수치로 판단할 수 없습니다. 거리 선택 기준을 탐색한 세션을 다시 평가한 결과이므로, 다른 주행 장면에서 독립 검증이 필요합니다. 정확한 후보 기준과 한계는 [거리 추정 기록](docs/DISTANCE_ESTIMATION.md)에 있습니다.

- RGB 영상: 640×480, 수집 FPS, 표시 FPS, 프레임 번호, 시뮬레이션 시간

- IMU: 가속도, 각속도, 나침반 / GNSS: 위도, 경도, 고도
- 충돌과 차선 이탈: 감지된 이벤트 목록


## Windows 실행

CARLA와 `hero` 차량을 먼저 실행하세요. 이 프로젝트는 시뮬레이션 맵이나 동기화 설정을 변경하거나 서버를 직접 tick하지 않습니다.

```powershell
cd C:\programming\carla
uv venv --python 3.12 .venv
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
uv pip install --python .venv\Scripts\python.exe "C:\CARLA_0.9.16\PythonAPI\carla\dist\carla-0.9.16-cp312-cp312-win_amd64.whl"
.\.venv\Scripts\python.exe -m monitor.qt.app
```

다른 CARLA 서버나 차량 역할을 사용할 경우 `--host`, `--port`, `--role`을 지정할 수 있습니다. 예: `--role hero --port 2000`.

## YOLO11n 실시간 검출

TensorRTx의 C++/CUDA 검출기와 TensorRT 엔진을 빌드한 뒤 프로젝트 폴더의 **`run_yolo11n.bat`을 더블클릭**하면 YOLO가 연결된 Qt 모니터가 실행됩니다. CARLA 서버와 `hero` 차량은 먼저 실행해 두세요. 기본 명령 `python -m monitor.qt.app`은 YOLO 없이 센서 모니터로 동작합니다. 빌드 과정은 [TensorRTx 빌드 기록](docs/PHASE_1_5_CMAKE.md)을 참고하세요.

PowerShell에서 실행하려면:

```powershell
& .\run_yolo11n.bat
```

실행 파일은 현재 개발 PC의 `.venv`, TensorRT, OpenCV 경로를 사용하고 필요한 파일이 없으면 경로를 출력합니다. 화면의 **실시간 탐지 시작/중지**와 **트래킹 시작/중지**는 별도 기능입니다. 좌우 화면에서 **원본, YOLO 검출, 트래킹, 레이더 융합 트래킹**을 각각 선택할 수 있습니다. 트래킹은 탐지가 켜져 있을 때만 동작합니다. 영상 추적기는 차량 클래스와 검출 상자의 겹침·중심 이동으로 ID를 유지합니다. 레이더 보조 추적기는 영상에 투영한 레이더 점의 거리·상대속도를 트랙 연결에도 사용합니다. 검출이 잠시 끊기면 최대 10개 처리 프레임 동안 예측 박스를 표시하며, 가림이나 차량 교차 시 ID가 바뀔 수 있습니다.

앱 시작만으로 기록하지 않습니다. **일반 기록 시작**은 원본 영상과 센서 데이터를, **YOLO 기록 시작**은 탐지 결과를, **YOLO+트래킹 기록 시작**은 영상 추적 기준선을, **YOLO+레이더 융합 기록 시작**은 영상 전용 결과와 레이더 보조 추적 결과를 함께 저장합니다. 네 기록 모드는 동시에 사용할 수 없습니다. AI 기록 버튼은 필요한 탐지·트래킹을 자동으로 켭니다.
